# UA News AI

Автоматична система українських новин для Telegram.

## Джерела новин

Система працює **виключно з налаштованими Telegram-каналами**.

- RSS-стрічки не використовуються;
- вебсайти не скануються;
- інтернет-статті не використовуються як резервні джерела;
- кожна новина для модерації має походити з одного з каналів у `TELEGRAM_SOURCES`.

## Можливості

- моніторинг Telegram-каналів у реальному часі;
- рівний пріоритет налаштованих каналів;
- дедуплікація;
- AI-редагування українською;
- оцінка важливості;
- закрита Telegram-модерація;
- кнопки Опублікувати / Відхилити;
- публікація тільки після підтвердження;
- SQLite-історія;
- Railway/Docker.
