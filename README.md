# UA News AI

Автоматична система українських новин для Telegram.

## Можливості
- RSS та офіційні новинні джерела;
- пріоритет України, потім Європи та світу;
- дедуплікація;
- AI-редагування українською;
- AI не повинен додавати факти, яких немає у матеріалі;
- оцінка важливості;
- закрита Telegram-модерація;
- кнопки Опублікувати / Відхилити;
- публікація тільки після підтвердження;
- SQLite-історія;
- Railway/Docker.

Telegram-бот сам по собі не може довільно читати будь-які чужі Telegram-канали. Такий моніторинг потрібно додавати окремо через дозволений спосіб доступу.
